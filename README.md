# TCIT Dev Challenge: Posts

Aplicación para gestionar Posts (nombre y descripción): crear, eliminar, listar y filtrar por nombre.

- **Frontend:** React + Redux
- **Backend:** API JSON en Node.js (Express)
- **Base de datos:** PostgreSQL
- **Infraestructura:** Google Cloud (Cloud Run + Cloud SQL)
